# 배움을 짓는 시간

순천승평중학교 음악교사 유정준의 수업과 성장 기록을 담은 웹저널입니다.

## 파일 열기

압축을 모두 푼 뒤 `index.html`을 더블 클릭하면 브라우저에서 볼 수 있습니다. `assets` 폴더와 나머지 파일은 함께 보관하세요. 별도 설치나 빌드가 필요하지 않습니다. 본문은 HTML 안에 포함되어 있어 인터넷 없이도 읽을 수 있으며, 온라인에서는 Google Fonts 서체를 불러옵니다. 서체를 불러오지 못하면 기기의 기본 한글 글꼴로 표시됩니다.

## GitHub Pages에 게시하기

1. GitHub에서 새 저장소를 만듭니다. 예: `teacher-journal`. GitHub Free에서 Pages를 이용하려면 공개(Public) 저장소로 만듭니다.
2. 저장소의 파일 업로드 화면에서 이 폴더 안의 `index.html`, `style.css`, `script.js`, `assets` 폴더, `.nojekyll` 파일을 올립니다. 상위 `growth-journal` 폴더 자체가 아니라 **그 안의 파일**을 저장소 첫 화면에 올려야 합니다.
3. 파일을 저장(Commit changes)합니다.
4. 저장소의 **Settings → Pages → Build and deployment**로 이동합니다.
5. **Source: Deploy from a branch**, **Branch: main**, **폴더: /(root)**를 선택하고 Save를 누릅니다.
6. 배포가 완료되면 같은 화면에 표시된 웹사이트 주소를 엽니다. 일반적으로 `https://계정명.github.io/저장소명/` 형태입니다.

공식 안내: [GitHub Pages 게시 원본 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 내용 수정

- 본문·제목·사진 설명: `index.html`
- 색상·글꼴·여백·모바일 배치: `style.css`
- 목차·읽기 진행 표시·사진 확대: `script.js`
- 사진: `assets/` 폴더
- `content.json`: 본문을 정리해 둔 참고 자료입니다. 이 파일만 고쳐도 화면이 바뀌지는 않습니다. 실제 화면 내용은 `index.html`에서 수정하세요.

## 구성

수업의 기록 / 다음 수업의 설계 / 함께 자라는 교사, 세 장으로 구성했습니다. 휴대전화용 목차, 현재 읽는 장 표시, 사진 확대, 키보드 조작과 동작 줄이기 설정을 지원합니다.

원문에 있던 개인 전화번호와 서명 이미지는 공개 웹페이지에서 제외했습니다. 본문은 사용자가 승인한 쉬운 표현을 반영했으며, 수업 사진은 제공된 성장계획서에서 가져왔습니다. 원본 스캔 해상도에 따른 화질 한계가 있습니다.
