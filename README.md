# 배움을 짓는 시간 — 성장계획 웹저널

수정된 성장계획서의 본문, 수업 사진, 공유 자료 링크와 QR 코드를 담았습니다. 본문 25개 문단마다 내용에 맞는 삽화와 한 줄 요약을 넣었습니다.

## GitHub Pages에 반영하기

1. 압축을 풉니다.
2. `growth` 저장소에서 현재 `index.html`이 있는 위치에 이 폴더의 파일을 올립니다.
3. `index.html`, `style.css`, `script.js`는 같은 이름의 파일을 교체합니다. `assets` 폴더도 하위 폴더를 포함하여 올립니다.
4. 변경 사항을 커밋한 뒤 GitHub Pages 배포가 끝나면 웹페이지를 새로고침합니다.

`assets/illustrations` 폴더의 그림 25개를 빠뜨리지 않도록 주의하세요. 별도의 설치나 빌드는 필요하지 않습니다. 기존 저장소의 다른 파일을 삭제할 필요는 없습니다.

## 구성

- `index.html`: 본문과 화면 구성
- `style.css`: PC·휴대전화·인쇄용 디자인
- `script.js`: 메뉴, 읽기 진행 표시, 사진 및 QR 확대
- `assets/`: 기존 사진, QR, 문단 삽화
- `content.json`: 성장계획서 본문 자료
- `resources.json`: 공유 자료 목록
- `illustrations.json`: 삽화와 문단 요약 연결 목록

삽화는 문단 내용을 설명하기 위해 AI로 제작한 그림입니다. 기존 수업 사진과 구분하여 사용했습니다. 본문 내용은 수정된 성장계획서를 유지했습니다. 글꼴은 Google Fonts에서 불러오며 연결되지 않으면 기기의 기본 한글 글꼴로 표시됩니다.

이 파일을 준비한 것만으로 공개 웹페이지가 변경되지는 않습니다. 저장소에 업로드해야 반영됩니다.
